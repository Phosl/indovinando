# Istruzioni repository

## Shortcut utente

- `tc` = testo commit
- I testi commit richiesti con `tc` vanno sempre scritti in inglese.

## Note

- Quando l'utente usa una shortcut definita qui, interpretarla con quel significato.
- Aggiungere nuove shortcut qui quando l'utente le introduce.
- prima riuso i componenti esistenti poi estendo quelli giusti
- evito doppioni o varianti parallele se non servono davvero
- utilizzo colori --var da global.scss
