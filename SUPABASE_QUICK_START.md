Copia TUTTO da: **DATABASE_SETUP_GAMES_ONLY.sql**

In Supabase:

```
SQL Editor
↓
New Query
↓
Incolla il SQL
↓
RUN (bottone blu)
```

### 3 Riavvia l'App

```bash
Ctrl+C
npm run dev
```
